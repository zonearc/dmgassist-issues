# DMGAssist: report a problem or suggest an idea

DMGAssist is a rotation helper for World of Warcraft (Midnight and WoW Forever).
**Download it on [CurseForge](https://www.curseforge.com/wow/addons/dmgassist)**: the CurseForge app keeps it up to date.

This page only collects reports and ideas. The add-on's code is not published here.

## Report a problem

1. In game, right after it happens, type **`/dmga report`** (or right-click the minimap button → *Report an issue*).
2. Write what went wrong and what you expected, and what you were doing.
3. Press **Ctrl+C**: your words and the report are copied together.
4. [Open a bug report](../../issues/new?template=bug_report.yml), paste with **Ctrl+V**, and press Create.

You'll get a reply here, usually with a fix in the next CurseForge update.
